# Объяснение решения

Идея на самом деле довольно простая. ( Ревёрснутый элемент = k - element[i-ый] массива)
Идём по массиву, встречаем элемент. Если ревёрснутый элемент, уже заложился в мапу, т.е. в массиве встретился элемент, который в сумме с текущим выбранным даст k, то выводим индекс заложенного +текущего.
Иначе - просто подкладываем дальше пока условие не выпадет нормальное.

## Оценка сложности

### Скорость

O(n) - идём по всему массиву. Самые худшие случаи, когда два числа стоят в самом конце.

### Память

O(n) - я выделяю память под MyDict() хи-хи. И она будет заполняться почти всеми эл-тами в самом худшем случае.

## Визуализация

### По шагам

#### Шаг 0

```text
индекс:    0    1    2    3
arr:     [ 1 ,  3 ,  4 , 10 ]
           ↑
complement = 7 − 1 = 6   →  в таблице нет
таблица:   { 1: 0 }
```

#### Шаг 1

```text
индекс:    0    1    2    3
arr:     [ 1 ,  3 ,  4 , 10 ]
                ↑
complement = 7 − 3 = 4   →  в таблице нет
таблица:   { 1: 0,  3: 1 }
```

#### Шаг 2

```text
индекс:    0    1    2    3
arr:     [ 1 ,  3 ,  4 , 10 ]
                ↑    ↑
                └────┘  3 + 4 = 7
complement = 7 − 4 = 3   →  есть в таблице, индекс 1
ответ:     [1, 2]
```

Элемент `10` даже не просматривается: ответ найден раньше.
