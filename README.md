# ID - 320671

## Запуск
Для того, чтобы пользоваться моим решением на компьютере надо иметь Python предустановленный.
Перед тем как локально запустить тесты советую скачать [uv](https://github.com/astral-sh/uv)
```bash
    pip install uv
```
Чтобы создать виртуальное окружение впервые:
```bash
    # Автоматом подтянутся нужные библиотеки и т.д.
    uv sync --all-groups
```
Далее
```bash
    source .venv/bin/activate # Linux
    source .venv\Scripts\activate # Windows
```
## Тесты
Будучи в корне репозитория для проверки тестов просто вписать команду
```bash
    pytest
```
